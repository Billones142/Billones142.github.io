## 📂 Proyectos Destacados

### 1. Home-Lab & Self-Hosting Infrastructure
**Descripción:** Implementación de un servidor doméstico basado en TrueNAS y Docker para la gestión centralizada de datos y servicios.
* **Tecnologías:** Docker, TrueNAS, Redes locales.
* **Valor:** Soberanía de datos, automatización de backups, scripting, ACL's.

### 2. Dotfiles & Workflow Optimization
**Descripción:** Configuración avanzada de entorno de escritorio en Arch Linux utilizando Hyprland, optimizando la productividad mediante scripts personalizados.
* **Tecnologías:** Lua, Bash, Hyprland.
* **Valor:** Eficiencia en el flujo de trabajo de desarrollo.
* **Enlace:** [Link a mis Dotfiles](https://github.com/Billones142/dotfiles)

### 3. Sistema Anti-cheat a nivel de Kernel (Linux)
**Descripción:** Proyecto final de carrera, todavia en desarrollo. Investigación y desarrollo de un sistema de seguridad para videojuegos que opera en el espacio de kernel de distribuciones GNU/Linux para detectar manipulaciones de memoria y procesos.
* **Tecnologías:** Rust, Linux Kernel Modules (LKM), System Calls, Bash.
* **Valor:** Seguridad de bajo nivel, monitoreo de integridad del sistema, gestión de privilegios y análisis de comportamiento de procesos.

### 4. Automatización y Control de Manufactura Aditiva (Klipper)
**Descripción:** Optimización y gestión de firmware personalizado para impresión 3D, integrando un sistema de control basado en Klipper y un mecanismo de respaldo automatizado.
* **Tecnologías:** Klipper/Marlin, Jinja2, GitHub Actions, Linux (SBC).
* **Valor:** Automatización de flujos de trabajo, control de versiones de configuraciones críticas y mantenimiento preventivo de infraestructura de hardware.
* **Backup Klipper Artillery SW X1:** [Backup](https://github.com/Billones142/Artillery-SW-X1)

### 5. Sistema de Auditoría y Digitalización de Votos (OCR + Web)
**Descripción:** Desarrollo de una plataforma integral para agilizar el recuento de votos mediante la digitalización de telegramas electorales. El sistema utiliza IA (OCR) para extraer datos automáticamente, permitiendo la verificación humana y la visualización de resultados en tiempo real.
* **Tecnologías:** Inteligencia Artificial (OCR), Backend (Bun/Typescript), Frontend (Web), SQL(PostgreSQL), Gestión de Roles (RBAC).
* **Valor:** Procesamiento masivo de datos, dashboards estadísticos dinámicos, seguridad basada en roles y optimización de tiempos en procesos críticos.
